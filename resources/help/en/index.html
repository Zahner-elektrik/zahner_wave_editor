Zahner Wave Editor

Build waveforms clearly from layers and time-ordered segments.

Inspect the result directly in the plot and export sampled values as CSV for Zahner Lab, or as binary doubles for a zahner_link wave resource.

Basic workflow

  1. Add or select a layer in the Structure dock.
  2. Add, insert, move, or resize segments. Edit the selected item in Properties.
  3. Set the document Value Rate and use Edit > Scale Entire Waveform when the complete signal needs amplitude or time scaling.
  4. Use Fit Waveform to review the full signal.
  5. Save the editable .zwj document or export the sampled values.

Disabled layers do not contribute to the combined waveform. An export can temporarily override the document value rate.

How layers are combined

The layers of a level are combined from top to bottom. The first active layer starts the result, and each one below it is either added or multiplied in - so the order in the Structure dock is part of the signal as soon as something multiplies. Mode, name and edge policy of the selected layer are edited in the Properties dock; a multiplying layer is marked with × in the tree.

A layer that is shorter than the document needs a rule for the time beyond its end, which the Outside setting provides:

  • Neutral - nothing changes: 0 when adding, 1 when multiplying. This is the default, and the reason a short window layer leaves the rest of the signal alone instead of silencing it.
  • Zero - always 0, so a multiplying layer cuts everything after its end.
  • Hold last - the nearest value of the layer's own curve, held before its start and after its end.
  • Loop - the layer repeats, with its own duration as the period.

Groups combine their layers among themselves first and take the result into their own level, which is what makes A + (B × window) possible - without a group, a multiplying layer would always act on everything above it. Add one with Structure > Add Group, put an existing layer into a new group from its context menu, and dissolve a group again with Ungroup. A group carries a mode and an edge policy of its own; with Loop or Hold last its whole subtree replays or freezes, formula segments included.

Windows and envelopes

A Window segment is the piece a multiplying layer needs: rectangular, Hann, Hamming, Blackman, Blackman-Harris, Tukey, Gauss, Kaiser, or a plain trapezoid with a rise and a fall time. The shape spans one repetition, so a repeat count turns it into a burst train. Amplitude and Offset scale it: 0.5 and 0.5 modulate between half and full instead of down to zero, and a negative amplitude turns the window into a notch.

Pulse voltammetry

The Electrochemistry category of Add Segment holds the three pulse methods, with the same parameters their IM7 jobs take. Unlike the other categories, each of these is a complete measurement waveform rather than a shape to build one from. All three walk a staircase from Start value towards End value in steps of Step value: the scan direction follows from start and end alone, so an end below the start gives a cathodic sweep and the step, pulse and amplitude values stay positive magnitudes.

Where the staircase begins differs between the methods, and the step count below the parameters is the plain quotient in every case. Normal pulse voltammetry sends its first pulse on the start value itself and its last on the end value, so it holds one level more than that quotient. The other two open one step past the start value.

  • Normal Pulse Voltammetry - the waveform rests on a Base value of its own and a pulse opens every step: the first pulse is the Start value, each following one stands one step value closer to the End value, and after every pulse the waveform drops back to the base value. Because the baseline is a separate value, the pulses may run towards it as well as away from it - a baseline of 0 with pulses walking from 500 mV down to 10 mV is written just like that. Step time is how long a step lasts, Pulse time how much of it the pulse holds.
  • Differential Pulse Voltammetry - a staircase with a pulse of Pulse value opening every step. Because the pulse comes first, it rises from the level held just before it and the step then settles one step value above that. Invert pulse sends it against the scan direction.
  • Square Wave Voltammetry - a square wave of ±Amplitude around the staircase, one step per Period. The raised half period comes first, whichever way the sweep runs.

How many steps there are follows from the parameters, and so does how long the sweep takes - the panel shows the step count below them, and keeps Duration at exactly one sweep while you edit. The duration field stays yours to change: a shorter one cuts the sweep off, a longer one holds its last level, and a Repeat count runs the whole sweep again. Editing any parameter fits the duration back to the sweep.

The pulse edges sit exactly where the times put them; unlike IM7, which builds a value list at a fixed rate, the editor evaluates the waveform directly and does not quantize the pulse time to a fraction of the step.

Finding your way around the plot

Every layer has a color of its own. The plot draws its curve in it, the Structure dock tints the layer's icons with the same color, and View > Show Legend lists them next to the result curve - so a curve can be traced back to the node it belongs to. A layer that does not reach the result, because it or one of its groups is switched off, is listed with a dashed line.

What you select is drawn a little wider and fully opaque while the other curves step back: a layer shows its whole curve that way, a segment only its own stretch of it. Groups have no curve of their own, so selecting one changes nothing in the plot. Clicking the plot background, or the empty space below the tree in the Structure dock, selects nothing and puts every curve back to the same weight. Dragging the background pans the view and keeps the selection.

The mouse wheel zooms around the pointer: over the plot it scales time, and with Ctrl the value axis. Over one of the two scales - the numbers below the plot or left of it - it scales that axis alone, so time can be stretched without touching the amplitude and the other way round. The double arrow of the cursor shows which direction the wheel works in there.

The two scales are handles for their axis in every other respect as well: dragging one shifts only that axis, which is how you follow a signal in time while keeping the amplitude you zoomed in on, and double-clicking one fits only that axis - the time scale to the whole document, the value scale to the values inside the visible time window. Fit Waveform remains the way to fit both at once.

The plot shows the values an export writes, the way a device plays them: each value at its own sample time, held until the next one, where the curve jumps straight to the new value. Nothing is drawn between two sample times that the output would not hold there, so the steps get finer when you raise the value rate.

Spectrum and statistics

View > Show Spectrum (FFT), or the button next to Fit Waveform, opens a second plot below the waveform: the amplitude spectrum of the result over the whole document. A sine of amplitude A shows a peak of height A, in volts, at its frequency. The divider between the two plots sets how much of the height each one gets. The mouse works on the spectrum just as on the waveform: the wheel zooms, dragging pans, and the two scales scale, shift and - with a double-click - fit their own axis.

Clicking into the spectrum shows its settings in the Properties dock, and selecting a segment brings the properties back:

  • Sample rate - the rate the output is sampled at for the transform. It starts at the value rate and follows it until you enter a rate of your own; entering the value rate itself ties it to the value rate again. The line below the field shows the rate as a multiple of the value rate. Since the output holds each value until the next one, a multiple of the value rate also shows the images of that staircase above the value rate.
  • Window - rectangular is exact for a waveform that repeats a whole number of times in the document; Hann, flat top and Blackman-Harris keep a frequency between two bins from leaking far, at the price of wider peaks. The amplitude is corrected for the window either way.
  • Logarithmic frequency and amplitude axes.

Below the settings the dock lists the figures of the analyzed signal - DC, RMS, AC RMS, minimum, maximum, peak, peak-to-peak, crest and form factor, the largest step and the slew rate it demands, the frequency resolution, the fundamental with its amplitude, the THD, and how much of the power lies just below the Nyquist frequency, which warns that the sample rate is too low for the signal. Copy puts them on the clipboard. The spectrum is only calculated while it is shown, in the background, and follows every edit.

Editing points on the canvas

A Points segment is shaped directly in the plot. Double-click on it to add a point, drag a handle to move it, and press Delete to remove the selected one. The same coordinates are listed in the Properties dock, where they can be typed in exactly.

  • Snap to grid - the bar above the plot decides where a dragged point or segment boundary can land. Grid sets how fine those positions are: a fraction of one grid cell, which gets finer as you zoom in and always stays a round number, or a fixed step you enter yourself. While the step follows the grid, the two fields show the step currently in effect.
  • Hold Ctrl while dragging to place a point freely, off the grid. With snapping switched off, Ctrl does the opposite and pulls the point onto the grid.
  • The arrow keys move the selected point from grid position to grid position, which is the precise way to set a value; Shift together with an arrow key jumps a whole grid cell.

Export formats

Which one you want depends on what reads the file:

  • CSV - one decimal value per line, rounded to the chosen number of significant digits. This is the text format the Zahner Lab Custom Waveform block reads.
  • Binary - raw little-endian IEEE-754 double values, 8 bytes per sample and nothing else. This is the byte stream the zahner_link Python library uploads as a WAVE resource, so create_resource_from_file() takes the exported file as it is - no conversion, no loss of precision. Zahner Lab does not read this format.

Neither format stores the value rate: sample i is the value at t = i / rate. Pass the rate the file was exported with as the job's value_rate.

Settings

Interface language, color theme and accent color are set in Edit > Settings and are remembered for the next start. The language follows the operating system until you choose one; a changed language is applied the next time the editor starts.
